# Gurpeet Singh — Portfolio

A responsive personal portfolio built with **React + Vite**.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customize before publishing

- Update the email address `hello@example.com` in `src/App.jsx`.
- Replace the sample project names, descriptions, and links in the `projects` array.
- The hero profile image currently uses the GitHub avatar URL. Replace its `src` with your own image path when ready.

## Deploy

This project can be deployed on Vercel, Netlify, or GitHub Pages after running `npm run build`.
